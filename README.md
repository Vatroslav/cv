# Vatroslav Mileusnić - product manager

Live site: https://vatroslav.github.io/cv/

Stories from my product work, told as answers to the questions I get asked in interviews, plus the terms I work on. Available in English and Croatian.

Three views of the same content:

- **By question** - pick a question and read the story at the depth you want
- **By map** - the stories placed on a map of product work
- **For AI** - everything as markdown, to paste into an AI assistant

This repository holds only the published static files. The site was built with Claude Code.
